Структуры данных: список, словарь, множество и кортеж

Список (list) сохраняет порядок и допускает повторения. Он удобен для ранжированной выдачи поиска: первый элемент — лучший результат. Словарь (dict) связывает ключ со значением; загрузчик документов хранит поля `text`, `source` и `filename` именно так.

results = [{"source": "a.txt", "score": 0.8}, {"source": "b.txt", "score": 0.5}]
print(results[0]["source"])
results.append({"source": "c.txt", "score": 0.2})

Множество (set) хранит уникальные значения и удобно для проверки принадлежности. Если важен порядок первых появлений, можно использовать словарь: он сохраняет порядок вставки.

sources = [item["source"] for item in results]
unique_sources = list(dict.fromkeys(sources))
print(unique_sources)

Кортеж (tuple) удобен для фиксированной пары значений, например символьного диапазона `(start, end)`. В отличие от списка, элементы кортежа нельзя заменить по индексу. Срез `results[:3]` получает первые три элемента списка и применяется при вычислении Hit@3.

Выбор структуры следует из операции: изменение последовательности — list, доступ по имени поля — dict, уникальность — set, фиксированная пара — tuple.
