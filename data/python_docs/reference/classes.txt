Классы: состояние и поведение в одном объекте

Класс полезен, когда несколько операций работают с одним состоянием. Например, поисковому индексу нужны и подготовленные фрагменты, и метод, который возвращает совпадения. `__init__` создаёт начальное состояние объекта; методы получают ссылку `self` на конкретный экземпляр.

class NoteBox:
    def __init__(self):
        self.notes = []

    def add(self, text):
        self.notes.append(text)

    def __len__(self):
        return len(self.notes)

box = NoteBox()
box.add("Проверить классификатор")
print(len(box))  # 1

Наследование позволяет уточнить поведение базового класса. Здесь новый класс меняет формат добавления заметки, но сохраняет список и способ подсчёта:

class TaggedNoteBox(NoteBox):
    def add(self, text):
        super().add(f"[учебное] {text}")

`__len__` — специальный метод, вызываемый функцией `len`. `@property` пригодится, если вычисляемое значение хочется читать как атрибут, но добавлять его следует только при понятной пользе. В проекте поисковые классы хранят индекс в экземпляре и дают методы `fit` и `search`.
