Строки Python при обработке документов

Тип str хранит последовательность символов Unicode. Строка неизменяема: `replace` или `strip` возвращает новую строку, исходная остаётся прежней. Это важно при подготовке данных: очистка может незаметно уничтожить форматирование программного кода.

message = "  Ошибка: файл не найден\n"
print(message.strip())              # убрать пробелы и перевод строки по краям
print(message.lower())              # привести буквы к нижнему регистру
print(message.replace("файл", "путь"))
print("ошибка" in message.lower())

`split()` без аргумента разбивает текст по пробельным символам, а `splitlines()` — по границам строк. Если потом собрать результат через один пробел, отступы и переводы строк пропадут. Для документов с Python-примерами лучше разрезать исходную строку по вычисленным смещениям, как делает загрузчик проекта.

parts = ["data", "ml_docs", "regression.txt"]
print("/".join(parts))
print("a,b,c".split(","))

Для безопасной нормализации окончаний строк можно заменить `\r\n` и `\r` на `\n`. Проверяйте, что нужные пустые строки и пробелы внутри блока кода сохранились.
