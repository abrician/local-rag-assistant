Порядок выполнения: условия, циклы и исключения

В Python отступ обозначает блок. `if` выбирает ветку, `for` обходит элементы, `while` повторяет действия до смены условия. Так, API выбирает один из двух методов поиска по полю `method`.

methods = ["tfidf", "embeddings"]
for method in methods:
    if method == "tfidf":
        print("Лексический поиск")
    else:
        print("Векторный поиск")

При обходе результатов `break` прекращает цикл, а `continue` пропускает текущий элемент. Счётчик нужно менять внутри `while`, иначе условие может навсегда остаться истинным.

count = 0
while count < 3:
    count += 1
    if count == 2:
        continue
    print(count)

Исключение сообщает, что обычный путь выполнения невозможен. Обрабатывайте конкретные ошибки там, где знаете, что с ними делать:

try:
    value = int("не число")
except ValueError:
    value = 0

Слишком широкий `except` может скрыть ошибку программы. В API иногда требуется перехватить сбой внешней зависимости и вернуть клиенту безопасное сообщение без внутреннего пути.
