Функции: небольшие действия с явными входами

Функция получает аргументы и возвращает результат через `return`. Если `return` не выполнен, результатом будет `None`. Именованные аргументы помогают понять вызов, а значение по умолчанию подходит для часто используемого варианта.

def take_first(items, limit=3):
    """Return at most limit items without changing the input list."""
    if limit < 0:
        raise ValueError("limit must be non-negative")
    return items[:limit]

print(take_first(["a", "b", "c", "d"], limit=2))

Параметры внутри функции локальны. Функцию проще тестировать, если она не читает скрытое состояние и не меняет входные данные без необходимости. В проекте `split_into_chunks` принимает текст и настройки окна, а возвращает список фрагментов.

Lambda — короткая функция-выражение, полезная для простого ключа сортировки:

records = [{"name": "a", "score": 0.3}, {"name": "b", "score": 0.9}]
print(sorted(records, key=lambda row: row["score"], reverse=True))

Для длинной логики лучше обычный `def`: его проще читать, документировать и проверять. `*args` собирает дополнительные позиционные аргументы, `**kwargs` — именованные, но использовать их без нужды не стоит.
