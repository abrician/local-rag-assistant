Первые шаги в Python на примере работы с заметками

Python выполняет выражения и инструкции в указанном порядке. Имя переменной ссылается на объект; тип принадлежит объекту и может меняться при новом присваивании. В учебном RAG-проекте строки представляют запросы и тексты, списки — документы, словари — поля каждого найденного фрагмента.

topic = "поиск"
max_results = 3
is_enabled = True
print(f"Тема: {topic}; результатов: {max_results}")

Значения `int` и `float` подходят для чисел, `str` — для текста, `bool` — для условий. Список изменяем, а кортеж обычно используют для фиксированной записи. Словарь даёт доступ к значению по ключу.

queries = ["Что такое regression?", "Как устроен список?"]
settings = {"method": "tfidf", "top_k": 3}
for query in queries:
    print(query, settings["method"])

Запустите файл командой `python filename.py` в активном окружении. Сообщение об ошибке обычно содержит тип исключения и строку, где возникла проблема. Для проверки версии используйте `python --version`; в этом проекте зафиксированные эксперименты выполнялись на Python 3.12.
