Классификация: выбор метки по признакам

Допустим, система сортирует обращения в поддержку по темам «оплата», «доставка» и «возврат». На вход она получает признаки сообщения, на выходе — одну из заранее известных категорий. Это задача классификации. Если меток две, задача бинарная; если больше двух и выбирается одна — многоклассовая. Когда меток у одного объекта может быть несколько, говорят о многометочной классификации.

Метрики стоит выбирать под стоимость ошибки. Accuracy — доля всех верных ответов, но она может обмануть на редком классе. Precision отвечает на вопрос: какая часть предсказанных положительных случаев действительно положительна? Recall показывает, какую часть настоящих положительных случаев мы нашли. F1 объединяет precision и recall. Матрица ошибок показывает TP, FP, FN и TN; по ней легко понять, какие ошибки важнее.

Минимальный воспроизводимый пример:
from sklearn.metrics import precision_score, recall_score

true_labels = [1, 0, 1, 0]
predicted = [1, 0, 0, 0]
print(precision_score(true_labels, predicted))  # 1.0
print(recall_score(true_labels, predicted))     # 0.5

Одна высокая метрика не делает модель подходящей: для фильтрации спама ложная блокировка и пропущенный спам имеют разную цену.
