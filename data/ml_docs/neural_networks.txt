Нейронная сеть: как веса учатся на примерах

Нейронная сеть преобразует входные числа последовательностью слоёв. Веса задают силу связей, а нелинейные функции активации позволяют описывать зависимости сложнее прямой линии. Для классификации выход может содержать оценки классов; для регрессии — одно число.

Один шаг обучения состоит из прямого прохода, вычисления функции потерь, обратного распространения градиентов (backpropagation) и обновления весов оптимизатором. Например, Adam использует историю градиентов для адаптации шага. Большой learning rate может мешать сходимости, а слишком маленький замедляет обучение. Эпоха — проход по обучающему набору; batch — часть набора для одного обновления.

Пример PyTorch с двумя признаками и одним выходом:
import torch

network = torch.nn.Sequential(torch.nn.Linear(2, 4), torch.nn.ReLU(), torch.nn.Linear(4, 1))
inputs = torch.tensor([[0.0, 1.0], [1.0, 0.0]])
targets = torch.tensor([[1.0], [0.0]])
optimizer = torch.optim.Adam(network.parameters(), lr=0.01)
optimizer.zero_grad()
loss = torch.nn.functional.mse_loss(network(inputs), targets)
loss.backward()
optimizer.step()

Этот шаг лишь демонстрирует механизм; для оценки качества нужны отдельные проверочные данные.
